# Feature Summary

Quick reference for all implemented and planned features in Foundry.

---

## ✅ CORE FEATURES (Implemented)

- **F-001** Sample shop + snapshot input
- **F-002** Local decision tools (9 tools)
- **F-003** Next-best-action brief (JSON)
- **F-004** Financial document import (Excel/CSV)
- **F-005** Copy collection reminder
- **F-006** Burmese language support
- **F-014** Database architecture (Neon + pgvector)
- **F-015** RAG architecture (768d embeddings)

## ✅ ENHANCED FEATURES (Implemented)

- **F-016** Admin dashboard
- **F-017** Google Drive integration (MCP)
- **F-018** AI Advisor with guardrails
- **F-019** Financial management system
- **F-020** Enhanced dashboard UI (tabbed)
- **F-021** Multi-specialist agents (9 total)
- **F-022** Document library system
- **F-023** Session & tenant management

## ❌ EXCLUDED BY DESIGN

- Expense coach (needs history)
- Staff handover (wrong job)
- Standalone inventory app
- What-if forecasts (fake certainty)
- Bank readiness report (approval risk)
